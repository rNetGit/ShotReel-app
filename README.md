# ShotReel

**Turn screenshots and clicks into narrated training videos and step guides. Free. Works offline.**

ShotReel is a Windows app for anyone who documents software: IT teams, trainers, support staff and consultants.
Record or import screens, write the steps, and ShotReel produces a narrated MP4, captions and a printable PDF guide.
Voice, rendering and capture all run on your PC. No account, no cloud service, no API keys.

## What you can do

- **Capture** a web app (every click becomes a step with the box already placed) or a Windows desktop app (the clicked control is named for you).
- **Or import** screenshots and short screen clips.
- **Annotate** with boxes, arrows, spotlights, numbered badges, text notes, zoom, and blur or redaction for sensitive data.
- **Narrate** with built-in offline English voices, or export the script, edit it with any AI or writer, and import it back.
- **Export** an MP4 (720p or 1080p, no watermark), captions (`.srt` and `.vtt`), and a step-guide PDF.
- **Reuse** your work: unchanged parts are not re-rendered, and projects share as a single `.shotreel` file.

| Concern | Answer |

| Our screens contain customer or internal data | Everything is processed on the computer. Redaction tools are built in. |
| We cannot use cloud tools | There is no cloud service to approve. The app has no account, sign-in or telemetry. |
| We do not want another subscription | The free version has no time limit, watermark or project cap. |
| We need to review it | Installer is signed; the licence and third-party notices are in the download. |

## Requirements

Windows 10 or 11 (64-bit), about 2 GB of free disk space, 8 GB RAM recommended. Rendering uses the CPU; a longer video takes longer.
